# MetroPro

Daily work app for metro station staff. Kotlin + Jetpack Compose (native Android).

- Package: com.zabii.metropro
- Updates: the app checks `version.json` on this repo's GitHub Pages 5 seconds after every launch and updates itself automatically.
- v1.0: full GUI (Golden Rush + Deep Forest theme), smooth screen transitions, working Money Calculator, auto-update system. Working features (TOM saving, WhatsApp reports, GPS camera) arrive in later automatic updates.
